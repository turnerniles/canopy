How it works

A WarioWare-style game doesn't use one long loop. It uses a run of short, bar-exact cues. A 2-bar interlude shows lives and score. Then comes a 2-bar microgame tune, in one of eight styles (chiptune, funk, mariachi, surf, jungle marimba, space disco, toy box, polka), while the fuse burns. A 1-bar win or lose jingle follows. Every 4 games there is a speed up to the next tempo tier (120 → 144 → 160 → 180 BPM). Game 12 is a boss stage. Everything is in C major or A minor, and the interlude ends on G7, so any cue can follow any other on the bar line.

Every cue is rendered by src/tracks/microgame.py on Canopy Orchestra's synthesized instruments, with no samples. Loops are seamless and come with ring-out tails. The engine pack, with OGG files per tier and cues.json, lands in out/microgame/.

API for a game: CanopyGame.start(), CanopyGame.press(), CanopyGame.resolve(true|false) (once per microgame; the result jingle lands on the next bar line), CanopyGame.getState(), and CanopyGame.on('cue'|'beat'|'microgame'|'result'|'speedup'|'boss'|'gameover', fn).
